## 我的方法

我不把 IP 当成人设包装，而是把它当成一套可验证的资产系统：

1. **定位资产**：你是谁、服务谁、解决什么高价值问题。
2. **内容资产**：观点、方法论、案例、文章、视频是否形成体系。
3. **信任资产**：是否有公开可验证的案例、反馈、项目、代码或证据链。
4. **搜索资产**：Google、百度、微信、知乎、掘金、GitHub 等信息是否一致。
5. **AI 可见度资产**：ChatGPT、Kimi、DeepSeek、豆包等是否能正确理解并推荐你。

这也是我做 GEO 的基础框架。
